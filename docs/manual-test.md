# Manual Test Checklist

빌드/릴리스 전 손으로 돌리는 회귀 테스트.

- **P0**: 핵심 매출/사용자 흐름. 깨지면 즉시 알 수 있음. 빌드 전 반드시 확인.
- **P1**: 자주 쓰는 기능. 빌드 전 권장.
- **P2**: edge case. 시간 있을 때.

> React Query DevTools 켜고 테스트하면 캐시 동작이 시각적으로 보임.

---

## P0 — 인증

- [ ] **Google 로그인** → 토큰 저장 → 홈 진입
- [ ] **Apple 로그인** (iOS) → 동일
- [ ] **회원가입** 플로우: 약관 동의 → 닉네임 입력 → 홈
- [ ] **로그아웃** → 토큰 삭제 → 로그인 화면 → 모든 user-scoped 캐시 클리어 (홈 다시 들어가도 옛 데이터 안 보임)
- [ ] **앱 콜드 스타트** (저장된 토큰 있는 상태) → 로그인 화면 안 거치고 바로 홈
- [ ] **토큰 만료 시 자동 refresh**: 오래 안 쓴 후 화면 진입 → 401 자동 복구 → 정상 동작
- [ ] **refresh 토큰도 만료** → 자동 로그아웃 → 로그인 화면

---

## P0 — 레시피 생성 (가장 핵심 흐름)

- [ ] **URL 입력 → 생성 버튼** → 시트 닫힘 → 홈 상단에 **"생성중" 카드** 표시
- [ ] **생성중 → 성공** 시 카드가 "최근 레시피"로 이동, 토스트/햅틱
- [ ] **생성중 → 실패** 시 카드에 **실패 표시** + 사용자가 인지 가능한 메시지
- [ ] **베리 1개 차감 확인** — 생성 직전 N개 → 생성 직후 N-1개 (홈 헤더 / 설정 / 생성 시트 모두 동일하게)
- [ ] **베리 부족 (0개)** 으로 생성 시도 → 충전 시트 자동 오픈
- [ ] **잘못된 URL** (유튜브 아닌 거) → 즉시 에러 메시지
- [ ] **YouTube 쇼츠 URL** (`/shorts/...`) → 정상 처리
- [ ] **쿼리 파라미터 포함 URL** (`?si=...`) → 정상 처리 (서버가 거부하면 클라이언트가 strip)
- [ ] **공유 익스텐션 콜드 스타트** — 앱 꺼진 상태에서 YouTube 공유 → 앱 켜지면서 생성 시트 자동 오픈 + URL 채워짐
- [ ] **공유 익스텐션 워밍** — 앱 백그라운드 상태에서 YouTube 공유 → 앱 포그라운드 + 시트 오픈

---

## P0 — 충전 → 베리 갱신

- [ ] **충전 시트 열기** (홈 헤더 베리 클릭 / 설정 / recipe-create-sheet 어디서든)
- [ ] **카카오톡 공유** 클릭 → 외부 카카오톡 앱 → 돌아오면 베리 +N
- [ ] **충전 후 모든 화면의 베리가 자동 갱신** — 홈 헤더, 설정, recipe-create-sheet (캐시 invalidation 동작)
- [ ] **충전 한도 도달** (5회) → 충전 시트에서 "오늘 더 못함" 메시지

---

## P0 — 레시피 상세 / 등록

- [ ] **카드 클릭** (홈/북마크/검색/큐레이션) → 상세 페이지 이동
- [ ] **유튜브 영상** 자동 로드 + 재생 가능
- [ ] **재료 카드** + **단계 카드** 정상 렌더
- [ ] **단계 클릭** → 영상이 해당 시간으로 seek
- [ ] **미등록 레시피** (큐레이션) → "잠겨있어요" 표시 + 등록 버튼
- [ ] **등록 버튼** → 베리 1개 확인 alert → 등록 → 잠금 해제 → 내 레시피 추가
- [ ] **이미 등록한 레시피** → 잠금 없이 모든 단계 표시
- [ ] **음성 모드 시작** (플로팅 버튼) → step 화면 이동

---

## P0 — 음성 모드 (Native Step)

- [ ] **숏폼/일반 영상 모두** 진입 가능
- [ ] **다음/이전 버튼**으로 스텝 이동
- [ ] **스와이프 제스처**로 스텝 이동
- [ ] **음성 명령**: "다음", "이전" 인식 → 스텝 이동
- [ ] **음성 인식 중 영상 볼륨 자동 다운** (ducking)
- [ ] **타이머**: 시작/일시정지/리셋
- [ ] **타이머 만료 시 알림**
- [ ] **앱이 잠금 상태로 안 가게** keep awake 동작
- [ ] **뒤로가기** → 상세 페이지로 복귀
- [ ] **숏폼 레이아웃**: 발자국이 우측으로 떨어짐, 일반 레이아웃: 아래로

---

## P1 — 검색

- [ ] **검색창 타이핑** → 자동완성 표시
- [ ] **검색 실행** → 결과 리스트
- [ ] **결과 카드 클릭** → 상세 이동
- [ ] **YouTube 검색 버튼** → 외부 YouTube 앱
- [ ] **최근 검색어** 표시 + 클릭 시 재검색
- [ ] **최근 검색어 삭제** (개별 / 전체)
- [ ] **검색 결과 0건** 빈 상태 표시

---

## P1 — 내 레시피 / 북마크

- [ ] **카드 표시** (썸네일/제목/채널/시간)
- [ ] **카드 길게 누르기** → 액션 시트 (삭제 등)
- [ ] **삭제** → 리스트에서 즉시 사라짐 + 다시 들어와도 사라진 상태
- [ ] **카테고리 필터** 칩 클릭 → 필터링 동작
- [ ] **카테고리 추가** 버튼 → 모달 → 생성 → 칩 추가됨
- [ ] **카테고리 삭제** → 칩 사라짐 + 그 카테고리 레시피는 "전체"에 남음
- [ ] **레시피를 카테고리로 이동**

---

## P1 — 큐레이션 (테마)

- [ ] **테마 카드** 클릭 → 테마 상세 이동
- [ ] **카테고리/분위기 모달** 자동 오픈 (해당 테마면)
- [ ] **카테고리 선택** → 필터링된 카드 리스트
- [ ] **dish 카드 클릭** → recipe_id 있으면 상세, 없으면 생성 시트
- [ ] **밤에 땡기는 (다크 테마)**: 배경 검정, 카드 투명, hook 카피 연보라
- [ ] **사랑 한 끼 / 봄동 / 버터떡** 정상 렌더
- [ ] **dish 수가 적은 테마**(버터떡)는 모달 안 뜸

---

## P1 — 설정

- [ ] **프로필 정보** (닉네임) 표시
- [ ] **베리 잔액** 표시 — 홈 헤더와 동일한 값
- [ ] **개인정보 처리방침** 클릭 → 페이지 이동 → 뒤로
- [ ] **서비스 이용약관** 클릭 → 페이지 이동 → 뒤로
- [ ] **카카오 문의** → 외부 카카오톡 오픈
- [ ] **로그아웃** → 확인 → 로그인 화면
- [ ] **회원 탈퇴** → 사유 → 의견 → 확인 → 모든 데이터 삭제 → 로그인 화면

---

## P1 — 알림 (Push)

- [ ] **알림 권한 요청** (첫 진입)
- [ ] **푸시 토큰 발급/등록** (서버에 저장됨, dev 콘솔로 확인)
- [ ] **푸시 알림 수신** (foreground)
- [ ] **푸시 알림 수신** (background) → 클릭 → 해당 화면으로 이동
- [ ] **로그아웃 시 푸시 토큰 unregister**

---

## P1 — 캐시/동기화

- [ ] **레시피 생성 후** → 홈의 베리, 내 레시피 둘 다 자동 갱신 (React Query DevTools로 invalidate 확인)
- [ ] **충전 후** → 모든 베리 표시 자동 갱신
- [ ] **북마크/등록 후** → 내 레시피, 상세 페이지 둘 다 자동 갱신
- [ ] **로그아웃 후** → 모든 user-scoped 캐시 클리어 (재로그인 시 옛 데이터 안 보임)

---

## P2 — UI 상태

- [ ] **로딩 스켈레톤** 표시 (모든 페이지)
- [ ] **빈 상태** 메시지 (레시피 0개, 검색 결과 0건 등)
- [ ] **에러 상태** 메시지
- [ ] **다크 모드** 자동 적용 (밤에 땡기는 테마)

---

## P2 — 네트워크 / 에러

- [ ] **오프라인** 상태 → 네트워크 에러 메시지
- [ ] **서버 500** → 사용자 친화적 메시지
- [ ] **느린 네트워크** → 로딩 스피너 / 스켈레톤
- [ ] **레시피 생성 timeout (3분 이상)** → 실패 처리

---

## P2 — Edge cases

- [ ] **앱 백그라운드 → 포그라운드 복귀** 시 데이터 갱신
- [ ] **다른 디바이스에서 상태 변경 후 동기화** (다중 디바이스 사용 시)
- [ ] **권한 거부** (마이크/알림) → graceful 처리
- [ ] **Korean IME 입력** (검색창, 닉네임 등) → 정상 동작
- [ ] **iPad** (supportsTablet) → 레이아웃 깨짐 없음

- [ ] tsc 통과 (`npx tsc --noEmit`)
- [ ] Metro 캐시 클리어 후 한 번 빌드 (`npx expo start -c`)
